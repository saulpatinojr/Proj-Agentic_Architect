# ADR 0002: Pin the APM CLI used by GitHub Actions

- Status: Accepted
- Date: 2026-09-11

## Context

The first live APM bootstrap run used `microsoft/apm-action@v1` without an explicit CLI version. The action installed APM 0.14.0, while the current APM release reported by the action was 0.30.0. APM 0.14.0 rejected the Kiro target even though the current APM target matrix supports Kiro and Antigravity.

## Decision

Pin `apm-version: 0.30.0` in the repository's APM GitHub Actions workflows until a deliberate upgrade is validated. Do not rely on the action's default CLI version for compatibility-critical behavior.

## Consequences

- CI uses the same explicitly selected APM generation that our target decisions were validated against.
- APM upgrades become reviewed repository changes.
- `apm.lock.yaml` and materialized projections remain generated by APM, not written by hand.
